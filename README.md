# Sekta Mama Content Room

Локальная рабочая версия контент-комнаты для Instagram-аккаунта `@sektamama`, собранная на основе механики Sekta SMM Content Room.

Внутри:

- обзор текущего публичного профиля;
- стартовая медиатека из 12 публичных обложек;
- идеальная сетка и контентные направления;
- комната роста с идеями;
- недельный план;
- конструктор каруселей и песочница обложек.

Числа и публикации зафиксированы как публичный срез на 17 августа 2026 года. Медицинские формулировки, истории участниц и материалы «до/после» требуют экспертной проверки и согласия на публикацию.

## Локальный запуск

Откройте папку проекта через локальный веб-сервер и перейдите на его адрес в браузере. Точка входа — `index.html`.
